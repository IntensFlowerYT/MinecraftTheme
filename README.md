# Minecraft Discord Theme

Un thème sombre inspiré de **Minecraft** pour Discord (compatible avec **BetterDiscord**, **Vencord** et autres clients alternatifs). Ce thème remplace l'interface par défaut par une esthétique bloc aux nuances de vert, avec un fond d'écran Minecraft personnalisé et un bouton d'accueil aux couleurs du jeu.

---

## 🌟 Fonctionnalités

- **Acoustique & Palette Minecraft** : Accents vert herbe (`#55FF55`) et tons sombres style roche/obscurité.
- **Bouton d'accueil personnalisé** : Icône Discord Minecraft superposée sur une texture de terre (*dirt*).
- **Fond de discussion** : Arrière-plan du tchat personnalisé avec une image du monde Minecraft.
- **Formes & Éléments** : Coins légèrement arrondis/carrés pour rappeler l'aspect bloc du jeu.
- **Boutons verts** : Style visuel reprenant l'interface des menus Minecraft.

## 🚀 Installation

### 1. Via Vencord / BetterDiscord (Lien direct)

1. Ouvrez les **Paramètres utilisateur** dans Discord.
2. Allez dans la section **Themes** (Thèmes).
3. Dans la zone **Online Themes** ou **Custom CSS** / **Themes Links**, ajoutez le lien suivant :

```text
[https://raw.githubusercontent.com/IntensFlowerYT/MinecraftTheme/main/MinecraftTheme.theme.css](https://raw.githubusercontent.com/IntensFlowerYT/MinecraftTheme/main/MinecraftTheme.theme.css)
